# 中文术语与一致性审校规则

本文是 Citavi 6 中文语言包的人工审校基准。自动审查结果只是候选项，不应被理解为必须全局替换的错误；资源键的用途和界面语境优先于字面一致。

## 已确认的术语原则

| 场景 | 推荐译法 | 说明 |
|---|---|---|
| 核心陈述缺失 | 无核心陈述 | 与“核心陈述”功能名称保持一致 |
| 密码设置动作 | 设置密码 | 用于按钮或可执行动作 |
| 在线资源位置标签 | 在线位置：{0} | 保留格式占位符，不得改写或删除 `{0}` |
| Contribution（文献类型标签） | 篇章 | 用于 Citavi 的篇章/书中贡献类文献类型 |
| Editor / Editors（作者贡献角色） | 编者 | 用于文献元数据中的编者角色；一般界面中的“编辑”动作不适用此规则 |
| Lecture（引用类型） | 报告 | 导入类型和文献类型标签应保持一致 |

## 必须按语境区分的同源英文

以下差异本身不构成错误，不能仅凭英文相同就批量统一：

- **Caption**：普通标题、文件标题、题注/图例可能分别使用“标题”或“题注”。
- **Direct quotation**：动作或按钮可用“直接引用”；名词性预览标签可用“直接引文”。若多个控件执行同一动作，应优先统一动作译法。
- **Editor**：元数据角色通常是“编者”；文本编辑器或编辑动作可以是“编辑”。
- **History**：学科/主题为“历史”；操作记录或历史列表可用“历史记录”。
- **In**：文献关系字段可译“收录于”；普通位置或介词语境可能使用其他译法。
- **Medium**：任务优先级的 Medium 是“中”；文献的存储介质是“存储介质”。
- **Multiple**：行距设置中的 Multiple 是“多倍行距”；一般数量语境可以是“多个”。
- **Period**：标点符号是“句号”；时间区间或年代语境可能使用“时期”。
- **Plain**：字体样式是“无格式”；纯文本语境是“纯文本”。
- **Read / Reader**：命令、权限、已读状态和有声书朗读者属于不同语义，不能强制使用同一译法。
- **Process failed**：操作流程、后台进程和任务状态要结合具体界面确认，不应仅按英文相同机械替换。

## 审校流程

1. 运行 `./tools/Test-TranslationTerms.ps1`，检查术语候选和同源译法差异。
2. 对每条候选查看资源键、所属 TSV、英文原文和界面用途。
3. 只自动修正语境明确、不会影响格式或资源键的差异；有歧义时保留并在本文记录例外。
4. 修改后运行 `./tools/Test-LanguagePack.ps1`（需要实际 Citavi bin 路径）以及仓库 CI 中的格式和构建测试。
5. 不得更改资源键、格式占位符、SmartFormat 表达式、HTML/RTF 标记或资源文件的列结构。

## 自动化边界

当前术语脚本采用报告模式，**不会自动重写翻译**。同一英文原文的多种译法是待审查候选，不等于错误清单；零条术语规则命中也不能证明整份语言包没有语义问题。完整的语言质量验收仍需要按文献类型、检索、导入导出、引文样式、Word 插件和许可页面进行人工检查。
