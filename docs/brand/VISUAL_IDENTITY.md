## 01. 品牌定位

这是面向 **Citavi 6 简体中文使用者**的独立语言本地化项目。视觉系统同时表达三种属性：学术文献工具、中文本地化、社区维护的增强组件。它应当在 GitHub 头像、README、Release 页面、安装程序与后续项目文档中保持一致。

**一句话品牌主张：** 让文献工具更懂中文。

**品牌关键词：** 学术 / 文献 / 中文 / 兼容 / 开放 / 可靠 / 可持续。

品牌名称优先级：

1. 完整中文：**Citavi 6 中文语言包**
2. 英文描述：**Chinese Language Pack**
3. GitHub 仓库标识：`citavi6_language_add-on_zh`

英文描述刻意采用 **Chinese Language Pack**，与项目目前已经实现的本地化功能保持一致。未来如果中文元数据等 Add-On 成为正式可用模块，可以在功能介绍中扩展为 `Chinese Language Pack & Add-ons`，不必修改图形标识。

> **独立性声明：** 本项目并非 Citavi 开发方运营或背书。图形为本项目独立制作，不得将其用作 Citavi 官方产品标志，页面显著位置应保留社区项目说明。Citavi 名称及相关商标归各自权利人所有。

## 02. 核心创意：文献之桥

主标志以一部打开的书为整体轮廓，由冷色、暖色双页组成。造型不是普通两片对称扇形，而是有内外厚度的多层书页，底部通过中央书脊连接成一个连续的视觉动势。

| 构成元素 | 图形表现 | 语义 | SVG 结构 |
|---|---|---|---|
| 左侧蓝色书页 | 渐变深蓝书页，嵌入白色弧形 C | Citavi 与学术软件的可靠性 | `front-page-blue`、`inner-white-c` |
| 右侧红色书页 | 珊瑚红至绯红的过渡，留白书写「中」 | 简体中文本地化 | `front-page-red`、`chinese-zhong` |
| 底部多层页边 | 弧形深蓝页带与白色留缝 | 文献积累、翻阅、延伸 | `book-folio-lines` |
| 中央书脊 | 左右轮廓向同一处汇合 | 两种语言的连接、知识互通 | `center-fold-highlight` |
| 右下红色书签 | 从右页底缘垂下，尾端 V 型缺口 | 检索、定位、收藏与引用 | `red-bookmark` |
| 标题中的红色 6 | 英文衬线字标的突出数字 | 对应 Citavi 6 | `citavi-six` |

**图形识别顺序：** 书本 → 蓝红双色 → C / 中 → 书签。任何尺寸的变体都应优先保留这个识别顺序。

### 02.1 造型结构规则

- 书本 **左蓝右红**，不能反转。
- 左页的 C 应表现为连续的**白色负形曲线**，不是叠放的标准字体 C；它的下笔画顺着左页卷入中央书脊。
- 「中」不是直接放大的任意字体，而是专门描摹的**不规则轮廓字形**；SVG 用单独路径定义，包含两个内孔。
- 两侧页底应至少表现出两层页边；其连接点需自然衔接，不能变成两个互不相干的书本图标。
- 书签应从右页下方延伸，与中央书脊错开。不要移到书本顶部。
- 书本的自然外接范围约为 **861 × 561 设计单位**；蓝/红主面积近似保持视觉均衡，但不要求机械对称。

### 02.2 留白、安全空间与比例

符号源的矢量视图为 `viewBox="170 132 911 590"`，实际主图形位于其内部，四周已留有基础余量。

- 独立符号外部建议再留 **0.10 W** 的安全区域（W 为符号本身的可见宽度），不要让 UI 边框、文字或其他图标贴近页尖。
- 主标志中文字以居中轴线对齐书脊，而不是分别对齐蓝/红页面。
- 方形 Logo 的上下布局为「图形—英文名称—中文名称—英文描述」，在保持现有模板时不任意换位。
- 横版仅可将图形置于左、文字置于右；不允许任意打散独立的 C、「中」或页层。

## 03. 颜色系统

### 03.1 基础识别色（设计令牌）

| 令牌 | HEX | RGB | 用途 |
|---|---|---|---|
| Citavi Blue | `#0353B8` | 3, 83, 184 | 蓝色核心识别色，边框与附属视觉 |
| Light Blue | `#0F86F3` | 15, 134, 243 | 页面高光、左上亮部 |
| Citavi Red | `#D81E06` | 216, 30, 6 | 中文本地化主强调色 |
| Bright Red | `#FF4B3A` | 255, 75, 58 | 右上页亮部、辅助强调 |
| Deep Navy | `#071B3C` | 7, 27, 60 | 深色背景、深色组件底色 |
| Text Navy | `#032454` | 3, 36, 84 | 标题文字、学术气质 |
| Slate Blue | `#627C93` | 98, 124, 147 | 英文说明、次要文案 |
| Paper White | `#FFFFFF` | 255, 255, 255 | 负形字、页缝、浅色背景 |

### 03.2 渐变与分层

主标志不只使用上述 8 种平涂颜色。实际矢量源中还使用经过视觉调节的多段渐变：

- `blue-front`：`#208EF2` → `#0866BE` → `#002455`。左页从明亮蓝到深海军蓝，深端朝向内侧/书脊。
- `blue-rear`：`#147BCD` → `#003D87` → `#032356`。后层页的阴影与厚度。
- `blue-edge`：`#1896F2` → `#0257A9` → `#001A46`。书本底部横向页带。
- `red-front`：`#B8000C` → `#E31511` → `#FF5540`。右页的红色纵深和亮部。
- `red-rear`：`#A50016` → `#D9191D` → `#FF583B`。背页厚度。
- `red-ribbon`：`#980825` → `#C5072D` → `#FF4040`。书签和页缝内红色。
- `red-six`：`#FF4E41` → `#C40716`。字标中的红色数字 6。

以上渐变来自实际 SVG 中的可编辑 `<linearGradient>` 节点。**不要**用单一的蓝色和红色填满全部页面，否则多层翻书的辨识度会显著下降。

### 03.3 配色约束

蓝色是**专业与载体**，红色是**中文与功能强调**；两种色块的面积应接近平衡。其他界面装饰不宜再加入大面积黄色、紫色或绿色。单色打印或丝印时，改用交付的单色版本，而不是自行去饱和/套滤镜。

## 04. 字体规范

| 层级 | 主字体建议 | 回退字体 | 字重 | 说明 |
|---|---|---|---|---|
| 英文主标题 `Citavi 6` | DejaVu Serif | Georgia, Liberation Serif, serif | Bold 700 | 与本次字形轮廓一致的庄重衬线形态；6 单独用红色 |
| 中文主标题 `中文语言包` | Noto Serif CJK SC | 思源宋体、系统宋体 | Bold 700 | 保持文献、书写、学术属性 |
| 英文副标题 | Lato | Arial, sans-serif | Regular 400 | 全大写，宽字距，低视觉权重 |
| README 正文 | 系统 UI 无衬线 | Noto Sans CJK SC 等 | Regular 400 | 界面可读性优先，不需要把正文全部做成衬线体 |

这里有两类可交付 SVG：

- **编辑版：** `logo-primary.svg`、`logo-dark.svg`、`logo-horizontal.svg` 等，标题为标准 `<text>`，可直接修改文案、大小与字体；外部电脑如果缺少指定字体，字宽可能不同。
- **发布版：** 对应的 `*-outlined.svg`，所有文字已转为 SVG 路径，避免平台字体替换。用于 GitHub 展示、正式发布或向别人交付时，推荐此版本。

独立符号、App Icon 的中文字「中」本身已经是路径，不依赖任何字体文件。**不要将字体文件打包进仓库**，只需提交矢量轮廓文件。

## 07. 浅色、深色、单色与反白

**浅色模式：** 使用 `logo-primary-outlined.svg`。页面以纯白为主，蓝色的深端形成足够的层次。README 深色主题会显示白色 SVG 画布，属于有意控制的设计效果。

**深色模式：** 使用 `logo-dark-outlined.svg` 或 `icon-dark.svg`。保留彩色书页，主文字反白，底色为 `#071B3C`。如果放在任意其他深底上，优先使用已有画布版本，避免文字对比度被破坏。

**单色模式：** 使用交付的 black/white 版本，保持「C」「中」的负形关系。此处单色指图形层全部使用单一前景墨色（负形孔洞为底色），不保留彩色渐变。

**禁止做法：** 把蓝/红页面交换；把「中」从右页挪到书脊；对图形单独拉伸变形；在复杂摄影背景上直接叠加无底白色细节；删除全部页缝；给全部笔画加统一描边；在正式发布中使用尚未授权的官方 Citavi Logo 替换本项目书本。

## 08. SVG 源文件的工程规则

本次交付的所有 SVG 都是可解析的 XML，使用 `<path>`、`<g>`、`<rect>`、`<text>` 与 `<linearGradient>`，而**不是**嵌入 PNG/JPEG 的 `<image>` 容器。

- 色块采用独立路径分组：`page-edges`、`front-pages`、`book-folio-lines`、`bookmark-layer`。
- 「中」为路径对象 `chinese-zhong`，使用 `fill-rule="evenodd"` 保留两处方形镂空。其轮廓来自对所选效果图局部白色字形的描摹和矢量化。
- 主要视觉基于手工 Bézier 曲线路径；图形可在 Inkscape、Illustrator 或 Figma 中继续逐点编辑。
- 主题变体采用多个完整、独立 SVG 文件，避免远程 CSS、在线字体、JS 或图片链接造成显示差异。
- 字标改变时，编辑原版并重新生成 `*-outlined.svg`；切勿直接编辑轮廓化字形以试图修改文字。
- SVG 的 `viewBox`、宽高可按需要改变；保持 `viewBox` 比例以避免书本被压扁。

### 08.1 参考配套工程

源参考效果图是外观参照，矢量文件是**新的重建资产**。若需要进一步逼近原图每一处微小高光，建议只针对页面梯度和书脊各别 Bézier 控制点做调整；禁止把原始位图贴回 SVG 当作“高保真方案”。

## 10. 维护、交付与验收标准

### 10.1 每次更新应检查

- [ ] 所有 SVG 文件能在现代浏览器或 Inkscape 正常打开。
- [ ] 图形没有外链图像、JS、滤镜蒙版依赖或不可信远程资源。
- [ ] 编辑版的主、副标题文字可以选中并修改。
- [ ] `*-outlined.svg` 不含 `<text>`，字号不会因缺字体改变。
- [ ] 独立符号保持 C / 中 / 红色书签三个关键识别元素。
- [ ] 明暗两种底色中，白色中文字和页缝足够清晰。
- [ ] 512 px 图标居中，无画布裁剪。
- [ ] 页面中保留“独立社区项目”的声明。

### 10.2 资源许可与权利边界

项目代码许可证与这套**原创图形资产**的授权不必自动相同。在决定是否开放商用之前应明确仓库中品牌资产的使用许可；若未来考虑使用第三方字体，需要核对字体授权。当前发行版本仅交付 SVG 字形轮廓和标准字体名称，不捆绑字体文件。项目中含有产品名称的文字并不意味着获得官方商标许可。

### 10.3 维护建议

版本号从 **v1.0.0** 开始。改动颜色或排版可以增加次版本；改变翻书/C/中三者的核心关系，应视为一次识别系统升级，必须同步修订本文件和所有图标变体。
